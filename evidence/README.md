# evidence/

真图运行的原始记录。一份文件 = 一次运行，**只增不改**。

## 命名

```
tc<用例编号>-<YYYY-MM-DD>-<agent>-<模型>.md
```

同一用例换了 Skill 版本或换了模型，就再开一份，不要在原文件上覆盖。

## 每份文件的结构

1. **运行条件**：日期、Agent 名、模型名、当时 `SKILL.md` 的行数、请求语原文
2. **输入**：图片清单（文件名 + 一句话说明图里有什么）
3. **输出**：第一次输出的完整原文，一字不改；有修正另附一段并标明是第几次
4. **判定**：按根 README 里该用例的「判定标准」逐条写 过 / 不过 + 看到了什么
5. **结论**：一句话

## 规矩

- 没跑过的不许写，跑完几组写几组，缺就是缺。
- 为了验证判定标准而手工造的坏样本，标题里写明"坏样本"，它只证明标准有效，不算 Skill 的成绩。
- 根 README 的「测试结果」一节只写结论并链到这里的文件，不写没有出处的"效果很好"。
